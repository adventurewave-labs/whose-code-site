# whose-code-site

The public case study for [whose-code](https://github.com/adventurewave-labs/whose-code),
our authorship scanner: **we scanned 20,245 commits of our own agent-built code
and published the complete result**, warts and all.

The page itself is `index.html` — a single static file, no build step, no
framework. Deploy target is Vercel's free tier.

## The receipt (method v0.2)

What the zero means, precisely: no commit was classified assisted or machine at
deciding confidence without a direct confession (trailer or bot account) on
these repos, under this method. It proves indirect signals never decided a
class. It is not a general accuracy guarantee.

## The law the scanner obeys

Classes are **assisted / machine / unknown**. There is no "human" class, by
design: commit messages and filenames are forgeable, so they can prove machine
involvement (a confession) but never human authorship. Positive human proof
comes from trail artifacts (order, gate verdict, human merge ruling), not from
git archaeology. Every record is cross-checked against `git rev-list` as the
authoritative history; anything unreadable fails the scan instead of guessing.

## Updating the numbers

Re-run the estate validation in the scanner repo, then update the table in
`index.html` and the one above in the same commit. The page and the receipt
must never disagree — the case study gate rejects numbers the table does not
show.
